## Levels

- `/ponytail lite` — build what's asked; name the lazier alternative.
- `/ponytail` — enforce YAGNI → reuse → stdlib → native → one line → minimum. Default full.
- `/ponytail ultra` — YAGNI extremist; delete before adding and challenge requirements.

## Skills

- `ponytail` — minimal implementation mode.
- `ponytail-review` — over-engineering review of a diff.
- `ponytail-audit` — ranked whole-repo bloat audit.
- `ponytail-debt` — harvest `ponytail:` shortcuts.
- `ponytail-gain` — published impact scoreboard.
- `ponytail-help` — this reference.

Say "stop ponytail" or "normal mode" to deactivate. `/ponytail off` also works.
